# Justin Oh

I build applied AI systems for learning, certification, and customer education, with a focus on agent orchestration, evaluation, and workflows people can inspect and control.

## Selected work

| Project | What it demonstrates |
| --- | --- |
| [Performance Lab](https://github.com/Cheeryoh/performance-lab) | Isolated exam environments, deterministic checks, AI rubric scoring, and human review. |
| [Launch Content Studio](https://github.com/Cheeryoh/launch-content-studio) | Five agents, four human review gates, structured validation, persistent run state, and audit logs. |
| [Drift Sentinel](https://github.com/Cheeryoh/drift-sentinel) | Product-to-course gap detection, risk prioritization, and remediation drafts. |
| [Signal Loop](https://github.com/Cheeryoh/signal-loop) | Customer-signal clustering and evidence-based education priorities. |
| [DemoForge](https://github.com/Cheeryoh/demo-forge) | Reproducible product-demo capture with highlights, pacing, captions, and audio checks. |
| [Voicebox Narration Runner](https://github.com/Cheeryoh/voicebox-narration-runner) | Resumable local narration batches with hash-bound approvals and bounded execution. |

## Engineering approach

Explicit state and review gates. Structured outputs checked against schemas. Deterministic tests alongside model judgments. Resumable runs with evidence about what happened.

The linked repositories document their setup, architecture, and validation scope.

**Tools:** TypeScript, Next.js, Node.js, Supabase/PostgreSQL, Playwright, and FFmpeg.
